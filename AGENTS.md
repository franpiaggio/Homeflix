# Instrucciones para agentes

Antes de modificar código, leer `docs/PROJECT.md`, `docs/DECISIONS.md` y `docs/ROADMAP.md`.

- Escribir de forma concreta y breve. Sin slogans, texto promocional ni explicaciones redundantes.
- Mantener separadas las capas de mensajes, búsqueda, descarga y reproducción.
- Priorizar funcionalidad, pruebas y compatibilidad con Android, iOS y navegador.
- Interfaz mínima y genérica. El diseño visual se trabajará después.
- Mantener el costo en cero, excepto VPS existente y posible almacenamiento.
- No subir secretos ni sesiones. No publicar paneles de administración.
- Usar fuentes de contenido autorizadas.
- No declarar funcional una integración sin probarla.
- Ejecutar pruebas y actualizar `docs/ROADMAP.md` al terminar cada cambio.
- No modificar otras aplicaciones de Coolify.
