# Agent instructions

Read `docs/PROJECT.md`, `docs/DECISIONS.md`, and `docs/ROADMAP.md` before making changes.

- Write all repository documentation in clear, concise English.
- Keep the README presentational: explain the product and its architecture, not a running list of unfinished work. A short "Work in progress" notice at the top is sufficient.
- Keep implementation status and verification details in `docs/ROADMAP.md`, not in the README.
- Do not claim an integration is verified unless it has been tested. Avoid unqualified claims in code or deployment instructions.
- Separate messaging, discovery, acquisition, and playback layers.
- Support Android, iOS, TVs, projectors, and browsers without device-specific assumptions.
- Keep interfaces minimal and generic; visual design comes later.
- Use free software and the existing VPS; optional storage is the only planned additional expense.
- Never commit credentials, sessions, or secrets. Keep administration private and use authorized content sources.
- Run relevant tests and update the roadmap after each milestone.
- Do not modify unrelated applications in Coolify.
